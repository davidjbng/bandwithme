The adapted layers live in `../../AppIcon.icon/Assets/`. Changes: select the
original body, mouthpiece/bell, neck and headstock paths; remove strings, keys,
controls, pickguard, tuners, drawn shadows and highlights; recolor; mirror the
saxophone; apply uniform scaling, rotation and translation on a 1024-square
canvas. Instrument contour coordinates are preserved exactly. SVG metadata is
removed from the adapted files. The source files here are retained for provenance
and are not referenced by the Icon Composer document.
