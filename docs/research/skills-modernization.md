`decision-mapping`, `edit-article`, `obsidian-vault`, `qa`, `request-refactor-plan`, `resolving-merge-conflicts`, `ubiquitous-language`, and `writing-great-skills` are absent from the selected current upstream tree. Repository GitButler conflict guidance remains authoritative.

## Deliberately not imported from Meine GAG

Prisma, Fastify, Unistyles, chatbot evaluation, corporate release and questionnaire conventions do not match this repo. React Native Testing Library guidance was not installed because this task selects Vitest and Playwright and does not introduce RNTL. Existing Expo and Playwright guidance already covers those areas. The separate modernization agents own the repository-specific release and dependency review skills.

## Setup audit outcome and limits

Repository targeting was verified as `davidjbng/bandwithme`, the active research ticket was claimed by the driving developer before work, and existing triage labels were compared with GitHub before creating missing ones. The existing agent-skills block was updated in place. All installation writes are scoped to this task; no branch was published and no app was deployed.

Validation checks 38 recorded skill hashes, discovery links, the 16 compatibility-copy hashes, preserved custom skill folders, launcher executability, and live tracker child/dependency queries. Skill commits bypass the hook after independent validation because its auto-stash failed during the attempted directory-to-symlink transition; the final tree preserves those directories. Device driving and Impeccable design execution are separate tasks; installing their instructions does not verify an app screen or native build.
