# Prototype: Tour Notes

Mode: Operate. Native iOS-first prototype at /prototype, using fictional band data and in-memory state. Existing authenticated routes stay intact. The user chose Tour Notes on the decision page.

## Direction contract

THESIS: A band's next useful decision takes priority over administrative dashboards. Tour Notes brings precise date columns and purposeful colour to ordinary native navigation.

OWN-WORLD: Pale green-grey ground #EAF0ED, petrol #164D4F, coral #AD4937; SF system UI typography, flat surfaces, restrained 16pt continuous corners. Dates align as fixed-width blocks; state also has explicit text.

STORY: See the next rehearsal, answer attendance, inspect the upcoming gig, vote on songs, then build that gig's ordered setlist. Members remain people with names and instruments.

FIRST VIEWPORT: Inline native product header, large two-line greeting, a petrol next-rehearsal panel with date and immediate yes/no actions; next-gig row and song-voting link below. Four system tabs: Übersicht, Termine, Songs, Band. Match the chosen 390x844 tour.html sketch's hierarchy and palette, expanding vertically for Dynamic Type.

FORM: Tour Notes, competitive challenger vernacular-ephemera-jet-age-ticket-wallet, chosen by the user. seed:a06e1ebefd3c3fe2. Native controls replace any sketch-drawn navigation. Light surfaces suit quick daytime planning; dark appearance adapts for dim rehearsal rooms.
